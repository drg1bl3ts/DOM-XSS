Lab 01: Greeting

Source: location.searchSink: innerHTML

What is happening

The form sends ?name=... in the URL. The script reads it from location.search (the source) and writes it into the page with innerHTML (the sink). The browser treats your input as HTML, not text.

Why innerHTML is a sink

innerHTML parses a string as HTML. Any tag in it becomes a real element. <script> tags inserted this way do not run, but event handlers like onerror do.

Payload 
<img src=x onerror=alert(1)>

The image fails to load, so onerror fires.

Fix 
greeting.textContent = "Hello, " + name;

textContent treats the value as plain text, never as HTML.
