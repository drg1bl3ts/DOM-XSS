Lab 02: Search results

Source: location.searchSink: document.write

What is happening

The script reads q from location.search and passes it to document.write(). The output is inserted into the page at the spot where the script tag sits, and the browser parses it as HTML.

Why document.write is a sink

Like innerHTML, it turns a string into live HTML. It runs while the page is still loading, so it is common in old code and ad or analytics snippets.

Payload 
<img src=x onerror=alert(1)>

Unlike innerHTML, document.write also runs <script>alert(1)</script> when the page is loading.

Fix

Do not use document.write. Build an element and set textContent:

const p = document.createElement("p");
p.textContent = "You searched for: " + query;
document.body.append(p);
