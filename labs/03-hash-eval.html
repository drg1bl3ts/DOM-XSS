Lab 03: URL calculator

Source: location.hashSink: eval

Put a sum after the # in the URL, for example 03-hash-eval.html#2+2, then reload.

Result:

What is happening

The script reads location.hash (everything after #) and gives it to eval() to do the maths. Whatever you put there runs as JavaScript.

Why eval is a sink

eval executes a string as code. There is no HTML involved, so there is no escaping trick. Any input that reaches it is code execution.

Good to know

The hash never goes to the server, so server-side filters and logs cannot see it. That makes it a favourite source for DOM XSS.

Payload 
03-hash-eval.html#alert(1)
Fix

Never eval input. Parse it instead, and reject anything that is not what you expect:

const match = expression.match(/^(\d+)\+(\d+)$/);
result.textContent = match ? Number(match[1]) + Number(match[2]) : "Invalid";
