Simulate another window sending a message:

What is happening

The page listens for message events and puts event.data into the board with innerHTML. It never checks who sent the message.

Why postMessage is a source

Any window that has a reference to this one (an iframe, a popup, or the page that opened it) can call postMessage on it. Without an event.origin check, any website can feed data to this handler.

Payload 
<img src=x onerror=alert(1)>

A real attacker would embed this page in an iframe and call postMessage on it.

Fix

Check the origin, and use textContent:

if (event.origin !== "https://trusted.example") return;
board.textContent = event.data;
