Lab 10: Delayed message

Source: location.searchSink: setTimeout (string)

What is happening

The script builds a line of JavaScript as a string, showMessage('YOUR INPUT'), and hands it to setTimeout. After a second the browser runs that string as code.

Why setTimeout is a sink

When setTimeout (or setInterval) gets a string, it works like eval. new Function(string) is the same. Your input sits inside quotes, so the trick is to close the quote, add your own code, then comment out the rest.

Payload 
');alert(1);//

The code becomes showMessage('');alert(1);//').

Fix

Pass a function, never a string:

setTimeout(function () { showMessage(msg); }, 1000);
