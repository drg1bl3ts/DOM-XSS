Lab 06: Saved nickname

Source: localStorageSink: innerHTML

What is happening

Save a nickname and it is stored in localStorage. Every time the page loads, it reads the value back and shows it with innerHTML. Reload after saving.

Why storage is a source

Storage feels safe because "we put it there". But the value came from a user, so it is still untrusted. This is stored DOM XSS: the payload fires on every visit, not just once. Cookies and sessionStorage work the same way.

Payload 
<img src=x onerror=alert(1)>
Fix 
profile.textContent = "Hi, " + nickname;

To reset the lab, run localStorage.clear() in the console.
