Lab 24: Bio (Handlebars)

Source: location.searchSink: {{{ }}} (triple-stache)Handlebars 4.7

What is happening

The template is <p>{{{ bio }}}</p>, compiled by Handlebars and rendered into the page with innerHTML.

Why {{{ }}} is a sink

Handlebars has two kinds of placeholder. Double braces, {{ bio }}, HTML-encode the value, same as everywhere else in this hub that's marked safe. Triple braces, {{{ bio }}}, are Handlebars' own escape hatch: "unescaped", meaning insert this exactly as given. It is one extra brace between safe and vulnerable.

Mustache.js, the template engine Handlebars describes itself as "largely compatible" with, uses the identical {{{ }}} convention for the same reason, so this lab covers both.

Payload 
<img src=x onerror=alert(1)>
Fix 
Handlebars.compile("<p>{{ bio }}</p>")

Drop to double braces unless you specifically need to render trusted HTML.

This hub originally shipped Handlebars 4.7.8, which three real CVEs affect — including CVE-2026-33937, a critical (9.8) remote code execution bug — all fixed in 4.7.9, since upgraded to here. None of them are reachable through this lab's own code (they need an attacker-controlled compiled template, not just template data), but a dependency with a public critical RCE has no business sitting in a repo meant to teach security.
