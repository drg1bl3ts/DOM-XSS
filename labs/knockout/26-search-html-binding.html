Lab 26: Bio (Knockout)

Source: location.searchSink: data-bind="html: ..."Knockout 3.5

What is happening

Knockout's normal text binding, data-bind="text: bio", always sets textContent and is safe. The html binding is the one that sets innerHTML instead, parsing the value as HTML.

Why the html binding is a sink

Knockout's own documentation warns about this directly: avoid using it with content from untrusted users, since it can open an XSS vulnerability. It exists for the same reason as every other sink in this hub, showing HTML a developer already trusts, like a CMS field, not raw user input.

Payload 
<img src=x onerror=alert(1)>
Fix 
data-bind="text: bio"
