Lab 05: Welcome banner

Source: window.nameSink: innerHTML

Simulate an attacker page that sets window.name and then sends you here:

What is happening

The script shows window.name in a banner using innerHTML.

Why window.name is a source

window.name survives navigation, even across different sites. An attacker's page can set window.name = "..." and then redirect to the victim page. The victim page reads the attacker's value. The URL looks clean because nothing is in it.

Payload 
<img src=x onerror=alert(1)>

Press the button above, or run window.name = "..." in the console and reload.

Fix 
banner.textContent = window.name;

Better still: do not trust window.name for anything.
