Lab 17: Bio (AngularJS)

Source: location.searchSink: ng-bind-html (sanitized)AngularJS 1.8.3

What is happening

This is the fixed version of lab 16. The string goes straight to ng-bind-html with the ngSanitize module loaded. Angular cleans it: tags like <b> stay, but onerror, <script> and javascript: URLs are removed.

Try to break it

Use the payloads from lab 16 and see them stripped. Then try different ones. A sanitizer is a safer sink, not a risk-free one. Bugs in sanitizers do get found, so keep the library up to date.

Try this 
<b>bold</b> <img src=x onerror=alert(1)>

The bold text stays. The onerror attribute is removed.
