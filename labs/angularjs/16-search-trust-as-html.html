Lab 16: Bio (AngularJS)

Source: location.searchSink: $sce.trustAsHtmlAngularJS 1.8.3

What is happening

The controller reads bio from the URL and wraps it in $sce.trustAsHtml(). The ng-bind-html directive then inserts it as HTML.

Why trustAsHtml is a sink

AngularJS has a security service called $sce. By default, ng-bind-html refuses to show a raw string. trustAsHtml tells Angular "I checked this, it is safe", which switches the protection off for that value. Here nobody checked. In modern Angular the same idea is called bypassSecurityTrustHtml.

Payload 
<img src=x onerror=alert(1)>
Fix

Do not trust user data. Use ngSanitize (see lab 17) or show it as text with {{ bio }} or ng-bind.
