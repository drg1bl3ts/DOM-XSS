Lab 23: Bio (Vue)

Source: location.searchSink: v-htmlVue 3

What is happening

Vue's normal way to show text, {{ bio }}, always HTML-encodes the value, the same safe behaviour as AngularJS's {{ }} when it isn't being compiled as a template (see lab 15 for what happens when it is). v-html is the directive that turns that protection off for one element and inserts the string as real HTML instead.

Why v-html is a sink

Vue's own docs say outright, in a dedicated "Security Note": "Dynamically rendering arbitrary HTML on your website can be very dangerous because it can easily lead to XSS attacks. Only use v-html on trusted content and never on user-provided content." It exists for cases like rendering HTML from a trusted CMS, not for user input.

Payload 
<img src=x onerror=alert(1)>
Fix 
<div class="output">{{ bio }}</div>

Use normal interpolation. If you truly need to render HTML, sanitize it first with a library like DOMPurify.
