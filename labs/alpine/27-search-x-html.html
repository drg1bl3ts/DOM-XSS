Lab 27: Bio (Alpine.js)

Source: location.searchSink: x-htmlAlpine.js 3.14

What is happening

Alpine is a single script tag added to otherwise plain HTML, no build step, which is why it's turned up in a lot of apps that are too small to justify React or Vue. Its normal text binding, x-text, is safe. x-html is the directive that sets innerHTML instead.

Why x-html is a sink

Alpine's own docs say outright: "Only use on trusted content and never on user-provided content. Dynamically rendering HTML from third parties can easily lead to XSS vulnerabilities." Same shape as Vue's v-html and Knockout's html binding in lab 23 and lab 26: a small, declarative framework gives you one named escape hatch out of its default text safety, and the bug is always using it on data that didn't need it.

Payload 
<img src=x onerror=alert(1)>
Fix 
x-text="bio"
