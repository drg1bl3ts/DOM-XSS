Lab 09: Leaving the site

Source: location.searchSink: location.href

Try 09-search-location-href.html?goto=../index.html

What is happening

Clicking the button sends the browser to the URL in the goto parameter by assigning it to location.href. This is a redirect feature.

Why location is a sink

Assigning a javascript: URL to location.href runs that code in the current page. A redirect to an https: URL on another site is an open redirect, which is a lesser bug. The javascript: scheme turns it into XSS.

Payload 
09-search-location-href.html?goto=javascript:alert(1)

Then click "Continue".

Fix 
const url = new URL(goto, location.href);
if (url.origin === location.origin) {
  location.href = url.href;
}
