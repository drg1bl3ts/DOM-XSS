Lab 04: Back link

Source: location.searchSink: a.href

Try 04-search-anchor-href.html?returnUrl=../index.html

Go back

What is happening

The script copies returnUrl from location.search into the href of a link. This needs one click from the victim.

Why href is a sink

An href can hold a javascript: URL. Clicking the link runs that code in the page's origin. This is the same idea as the src of an iframe or the action of a form.

Payload 
04-search-anchor-href.html?returnUrl=javascript:alert(1)

Then click "Go back".

Fix

Only allow URLs with a safe scheme:

const url = new URL(returnUrl, location.href);
if (url.protocol === "http:" || url.protocol === "https:") {
  back.href = url.href;
}
