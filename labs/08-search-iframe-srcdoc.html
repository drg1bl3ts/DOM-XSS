Lab 08: Preview frame

Source: location.searchSink: iframe.srcdoc

What is happening

The script builds a tiny HTML document from title and assigns it to the srcdoc of an iframe.

Why srcdoc is a sink

srcdoc is a whole HTML document. It is parsed like a normal page, so <script> tags do run, unlike with innerHTML. The frame shares the parent's origin, so its code can reach the parent page, cookies and storage.

Payload 
<script>alert(parent.location.href)</script>

The parent access shows the frame is same-origin with the page.

Fix

Put the text into the frame as text, or add a sandbox attribute with no allow-scripts:

preview.sandbox = "";
preview.srcdoc = "<h1>" + escapeHtml(title) + "</h1>";
