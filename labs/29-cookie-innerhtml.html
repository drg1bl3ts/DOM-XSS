Lab 29: Welcome back

Source: document.cookieSink: innerHTML

Simulate a cookie an attacker got set some other way (see below), then reload:

What is happening

The script reads a lastViewedItem cookie and shows it in a banner with innerHTML. Reload after setting the cookie to see it fire.

Why document.cookie is a source

A cookie value is only as trustworthy as whatever set it, and cookies get set from more places than you might expect: a server response header, a sibling subdomain (sub.example.com can set a cookie for .example.com that www.example.com will also read), or occasionally JavaScript on the page itself storing something a user typed. If any of those paths lets an attacker influence the value, and this page trusts it blindly, it's the same bug as every other source in this hub.

Payload 
<img src=x onerror=alert(1)>

Press the button above, or run document.cookie = "lastViewedItem=..." in the console and reload.

Fix 
banner.textContent = "Welcome back, we see you last viewed: " + lastViewedItem;
