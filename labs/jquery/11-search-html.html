Lab 11: Greeting (jQuery)

Source: location.searchSink: $.html()jQuery 4.0.0

What is happening

Same bug as lab 01, written with jQuery. .html(value) sets innerHTML under the hood, so the value is parsed as HTML.

Why .html() is a sink

jQuery does one extra thing: it finds <script> tags in the string and runs them itself. So unlike plain innerHTML, script tags work here.

Payload 
<img src=x onerror=alert(1)>
Fix 
$("#greeting").text("Hello, " + name);

.text() is the jQuery version of textContent.
