Lab 14: Back link (jQuery)

Source: location.searchSink: $.attr("href")jQuery 4.0.0

Try 14-search-attr-href.html?returnUrl=../../index.html

Go back

What is happening

Lab 04 again, with jQuery. .attr("href", value) sets the attribute, and the link runs javascript: URLs when clicked.

Why .attr() is a sink

jQuery does not check the value. The risky attributes are the same as in plain JS: href, src, action, formaction, and any on... event attribute.

Payload 
14-search-attr-href.html?returnUrl=javascript:alert(1)

Then click "Go back".

Fix 
const url = new URL(returnUrl, location.href);
if (url.protocol === "http:" || url.protocol === "https:") {
  $("#back").attr("href", url.href);
}
