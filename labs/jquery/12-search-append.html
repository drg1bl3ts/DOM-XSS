Lab 12: Comment list (jQuery)

Source: location.searchSink: $.append()jQuery 4.0.0

    What is happening

    The script builds a string of HTML, <li>YOUR INPUT</li>, and passes it to .append().

    Why .append() is a sink

    Many jQuery methods accept HTML strings, not only .html(): .append(), .prepend(), .after(), .before(), .wrap(), .replaceWith(). If you pass a string, it is parsed as HTML.

    Payload 
    <img src=x onerror=alert(1)>
    Fix

    Build the element, then set its text:

    $("#comments").append($("<li>").text(comment));
