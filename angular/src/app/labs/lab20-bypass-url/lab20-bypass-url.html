Go back

What is happening

By default, Angular blocks javascript: URLs in a bound [href] and replaces them with a harmless value. bypassSecurityTrustUrl() turns that check off for this one value, the same way bypassSecurityTrustHtml did for HTML in lab 19.

Payload 
?lab=20&returnUrl=javascript:alert(1)

Then click "Go back".

Fix 
const url = new URL(raw, location.href);
this.returnUrl = (url.protocol === 'http:' || url.protocol === 'https:') ? url.href : '#';
// no bypass needed, Angular allows plain http(s) strings in [href] already
